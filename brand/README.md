# ZAP brand

Hand-drawn vector logo (no AI image generation). Open the SVGs in Figma, Canva
(upload as SVG), Illustrator or Inkscape to edit.

**Idea:** ZAP = *Zenith Arunachal Pradesh*. The top stroke of the **Z** is a
horizon with a single peak (Arunachal, "land of the dawn-lit mountains") and
the sun sits beside the summit (zenith / dawn). The wordmark uses the same
5.5-unit monoline stroke; the **A** doubles as a peak.

| File | Use |
| --- | --- |
| `zap_mark.svg` / `zap_mark_light.svg` | Symbol on light / dark backgrounds |
| `zap_logo_horizontal.svg` / `_light.svg` | Symbol + ZAP wordmark |
| `zap_app_icon.svg` | 1024 px store / launcher icon (Play Store wants a 512 px PNG export) |
| `zap_icon_foreground.svg` | Android adaptive-icon foreground; background colour `#233E42` |

**Colours:** Atlantic Waves `#233E42` (mark), Child of Light `#F0F4F8`
(background / reversed mark), Aruba Aqua `#D2DDD4` (sun on dark).

**Clear space:** keep at least the sun's diameter free around the mark.
**Minimum size:** 16 px for the mark; 24 px tall for the horizontal logo.
